# 亲属关系地图

在卫星地图上标注亲属的家，自动推算任意人对「我」的称呼。解决春节走亲戚「不知道怎么叫」的问题。

纯前端：HTML + CSS + 原生 JavaScript + Leaflet，无框架、无构建、无数据库。数据只存浏览器本地。

## 快速开始

```bash
python server.py
# 浏览器打开 http://localhost:8000
```

任何静态服务器都可以（甚至直接双击 index.html 的部分功能可用，但推荐本地服务器）。

## 使用

0. **档案**：首次打开选「新建档案」——可先填**主要居住地地名**并搜索选点，建档后自动建成第一个区域（也可留空，进档后再建）；左上角档案栏可切换，各档案数据互相独立
1. **划定区域**：侧栏「区域」→ 用「搜索地名」添加（搜索框也支持 `纬度,经度` 直输），或「＋ 地图上框选新区域」手绘（双击闭合、可撤销）。**框选时实时显示当前跨度；闭合瞬间校验**，跨度超 20km / 顶点重合 / 三点共线不围出面积 → 自动撤销本次框选并提示重新划定。建区上限约 20km，相邻但分开的居住地（如父亲村/母亲村）请各建一个区域、切换查看
2. **区域内浏览**：默认只加载当前区域的卫星瓦片（区域外不请求，省流量）；平移被锁定在区域内（拖不出去），切换区域即时换场
3. **添加人物**：菜单 → 添加人物 → 进入放置模式（此时平移解锁，可找区域外的位置）→ 点击地图落点 → 填姓名/性别/手填称谓 → 确定。找不到位置可先在侧栏搜索结果点「定位」跳过去。落点在当前区域外会询问：拓展区域范围 / 归入其他区域
4. **标记「我」**：编辑某人物 → 勾选「标记为“我”」（称谓推算的起点，全图只能有一个）
5. **建立关系**：点击某人标签 → 信息卡 → 「+ 关系」→ 选择「A 是 B 的 某称谓」→ 添加
6. **看称谓**：建立关系链后，点任意人，信息卡自动显示他对「我」的称呼（红色徽章）；推算不出时显示关系路径（灰色徽章）
7. **人物关系图**：菜单 → 人物关系图，按代际分层展示；悬停高亮到「我」的路径，点击节点飞到地图
8. **搜索**：底部搜索框，支持姓名 / 推算称谓 / 手填称谓
9. **数据管理**：导出 JSON 文件备份；导入 JSON 恢复（覆盖前会确认）

**多设备/多人的数据同步**：数据只存在各自浏览器的 localStorage（按档案分键），git 只同步代码不同步数据。要把数据带给别人或换设备 → 导出 JSON → 传输文件 → 对方导入。

首次打开自带演示数据（横幅提示），点「清空，开始记录自己的数据」即可开始自己的家族。

## 数据格式（v3）

```json
{
  "version": 3,
  "regions": [
    { "id": "R1", "name": "老家", "polygon": [[纬度, 经度], ...] }
  ],
  "activeRegionId": "R1",
  "persons": [
    { "id": "唯一id", "name": "姓名", "gender": "m|f|空", "titles": ["手填称谓"],
      "lat": 纬度, "lng": 经度, "regionId": "R1" }
  ],
  "relations": [
    { "from": "人物id", "to": "人物id", "type": "父亲" }
  ],
  "rootId": "标记为“我”的人物id"
}
```

- 关系语义：`from` 是 `to` 的 `type`（如 `{from: 伯伯, to: 爸爸, type: 哥哥}`）
- 可用关系类型见 kinship.js 的 TYPE_GROUPS（祖辈/父辈/平辈/晚辈/姻亲）
- 旧版 `buildings` 数组、v2（无区域）导入时自动迁移：v2 数据会合成一个区域，人物全部归入
- 人物的 `regionId` 决定落点校验时归属哪个区域

## 称谓引擎 kinship.js

规则表 + 反向逆表 + BFS 最短路径。特点：

- 规则与代码分离，可独立测试、可复用于小程序等其他端
- 最短路径优先、防环、同辈分长幼精确区分（伯父/叔父）
- 推算不出时回退为可读的关系路径（如「孙子的儿子」），支持手填称谓兜底

测试：`node tests/kinship.test.js`（引擎 47 条断言）、`node tests/region.test.js`（区域几何校验 13 条断言）

## 隐私

- 数据仅存浏览器 localStorage，不上传任何服务器
- 导出的 JSON 文件请自行保管
- 演示数据使用非私人坐标；真实坐标建议只存在本地与导出文件中


## 瓦片说明

默认卫星底图：Esri World Imagery（免注册免 key）。config.js 可切换本地瓦片目录（`tiles/{z}/{x}/{y}.png`）或配置其他网络源。

v1.8 行为：

- 瓦片加载范围锚定**当前区域多边形外扩 50%**（`CONFIG.VIEW.EXPAND`），区域外不请求；Leaflet 在每个缩放级别自动按边界筛选，与手绘/搜索建区的方式无关
- 平移有**硬边界**：地图拖不出当前区域外扩范围（`maxBoundsViscosity: 1.0`），像游戏地图"越界移不过去"
- 缩放也受限：缩到"区域外扩范围恰好铺满视口"那一级就缩不动了（`syncMapPan` 按视口动态算 `minZoom`，窗口尺寸变化时重算）；绘制新区域 / 放置人物时临时解锁
- 无区域（演示/空档案）时不限制范围
- 建区尺寸校验 `REGION_MAX_SPAN_KM`（默认 20km，超出拦截）/ `REGION_MIN_SPAN_KM`、`REGION_MIN_AREA_KM2`（过小或共线拦截）；手绘闭合即校验，搜索建区超限则弹窗询问
- 打开档案/切换区域时的初始视野：区域外扩 50% 恰好铺满视口（与缩放下限同一级）；无区域时才用 `CONFIG.VIEW.MAX_ZOOM`（15）限制"看全部人物"的视野
