# 亲属关系地图

在卫星地图上标注亲属的家，自动推算任意人对「我」的称呼。解决春节走亲戚「不知道怎么叫」的问题。

纯前端：HTML + CSS + 原生 JavaScript + Leaflet，无框架、无构建、无数据库。数据只存浏览器本地。

## 快速开始

```bash
python server.py
# 浏览器打开 http://localhost:8000
```

任何静态服务器都可以（甚至直接双击 index.html 的部分功能可用，但推荐本地服务器）。

## 使用

0. **档案**：首次打开选「新建档案」——可先填**主要居住地地名**并搜索选点，建档后地图会**定位到那里**（不会自动建区，区域仍需你框选/点选划定）；也可留空，进档后再定位。左上角档案栏可切换，各档案数据互相独立
1. **划定区域**：侧栏「区域」→ 「＋ 地图上框选新区域」手绘（双击闭合、可撤销）；或先「搜索地名」把地图**定位**过去（搜索只定位、不建区），再点「缓存本区离线图」/框选。**框选时实时显示当前跨度；闭合瞬间校验**——跨度超 20km / 顶点重合 / 三点共线 / **边框自相交（"8 字形"这类边穿过边）** → 自动撤销本次框选并提示重新划定。建区上限约 20km，相邻但分开的居住地（如父亲村/母亲村）请各建一个区域、切换查看。区域列表每条带 ✕ 可删除，**最后一个区域也可以删**：删光后地图不再显示区域框、平移解锁，人物原样保留；数据里会记 `regionsCleared` 标记，防止重新打开页面时按人物位置自动"长"回区域——重新框选即自动撤销该标记。搜索结果每条带来源徽章（高德/天地图/Esri/OSM），国内使用请先在 config.js 填高德或天地图 key（免费，见下文「地名搜索」）
2. **区域内浏览**：默认只加载当前区域的卫星瓦片（区域外不请求，省流量）；平移被锁定在区域内（拖不出去），切换区域即时换场
3. **添加人物**：菜单 → 添加人物 → 进入放置模式（此时平移解锁，可找区域外的位置）→ 点击地图落点 → 填姓名/性别/手填称谓 → 确定。找不到位置可先在侧栏搜索地名，点结果定位过去再放置。落点在当前区域外会询问：拓展区域范围 / 归入其他区域
4. **标记「我」**：编辑某人物 → 勾选「标记为“我”」（称谓推算的起点，全图只能有一个）
5. **建立关系**：点击某人标签 → 信息卡 → 「+ 关系」→ 选择「A 是 B 的 某称谓」→ 添加
6. **看称谓**：建立关系链后，点任意人，信息卡自动显示他对「我」的称呼（红色徽章，推算不出时为关系路径灰色徽章），正名下方给出**俗称**（如「高祖父」又叫「老太爷 · 祖爷爷 · 太爷爷」），下方的**称谓换算**区同时给出两个方向——我称呼他 / 他称呼我（含辈分行、也称俗称）。父辈年龄相差大、出现同年龄段但辈分不同的情况（如小叔只比自己大 2 岁）时会显示 ⚠ 警示：称呼看辈分不看年龄
7. **人物关系图**：菜单 → 人物关系图，按代际分层展示；悬停高亮到「我」的路径，节点称谓悬停显示俗称，点击节点飞到地图
8. **搜索**：底部搜索框，支持姓名 / 推算称谓 / **俗称** / 手填称谓（搜「太爷爷」能找到两位曾祖辈）
9. **数据管理**：导出 JSON 文件备份；导入 JSON 恢复（覆盖前会确认）

**多设备/多人的数据同步**：数据只存在各自浏览器的 localStorage（按档案分键），git 只同步代码不同步数据。要把数据带给别人或换设备 → 导出 JSON → 传输文件 → 对方导入。

首次打开自带演示数据（横幅提示），点「清空，开始记录自己的数据」即可开始自己的家族。

## 数据格式（v3）

```json
{
  "version": 3,
  "regions": [
    { "id": "R1", "name": "老家", "polygon": [[纬度, 经度], ...] }
  ],
  "activeRegionId": "R1",
  "persons": [
    { "id": "唯一id", "name": "姓名", "gender": "m|f|空", "age": 年龄或null, "titles": ["手填称谓"],
      "lat": 纬度, "lng": 经度, "regionId": "R1" }
  ],
  "relations": [
    { "from": "人物id", "to": "人物id", "type": "父亲" }
  ],
  "rootId": "标记为“我”的人物id"
}
```

- 关系语义：`from` 是 `to` 的 `type`（如 `{from: 伯伯, to: 爸爸, type: 哥哥}`）
- 可用关系类型见 kinship.js 的 TYPE_GROUPS（祖辈/父辈/平辈/晚辈/姻亲）
- 旧版 `buildings` 数组、v2（无区域）导入时自动迁移：v2 数据会合成一个区域，人物全部归入
- `regionsCleared` 标记：删光区域后置位并随「导出数据」一起保存，导入/加载时区分「旧格式缺区域字段（需合成）」与「用户主动删光（保留空）」两种情况
- 人物的 `regionId` 决定落点校验时归属哪个区域

## 称谓引擎 kinship.js

规则表 + 反向逆表 + BFS 最短路径。特点：

- 规则与代码分离，可独立测试、可复用于小程序等其他端
- 最短路径优先、防环、同辈分长幼精确区分（伯父/叔父）
- 推算不出时回退为可读的关系路径（如「孙子的儿子」），支持手填称谓兜底
- **双向称谓换算** `Kinship.mutual(我id, 对方id)`：一次给出「我称呼他」与「他称呼我」两个方向及辈分代差 `genDiff`（正=对方低几辈，负=高几辈），间接（多级关系链）人物同样适用
- **正反两个方向都能推**：逆称表 `INV` 覆盖关系表单里全部 32 种类型，所以关系无论从哪一头录入都一样——记成「我 是 爷爷 的 孙子」和记成「爷爷 是 我 的 爷爷」都能同时得到「我 → 爷爷」和「爷爷 → 我」；只记了「侄子」这种长幼不明的，会给「伯父/叔父」并继续接链，不会断成路径
- **同龄不同辈提示**：信息卡里两人年龄差 ≤10 岁但 genDiff ≠ 0 时，显示「⚠ 同年龄段不同辈」警示——年龄相差大导致叔父与侄子同龄这类情况，称呼依然以辈分为准
- 多级链规则已覆盖：堂侄（堂兄弟|儿女→堂侄/堂侄女）、祖辈兄弟（爷爷|兄弟→伯祖/叔祖，其儿女→堂叔/堂姑）
- **本土称谓词表（五服代际）**：长链不再退化成「爷爷的爷爷」这种平铺路径，而是逐代接出中国传统的正名——

  | 代 | 直系尊亲属（父系） | 直系卑亲属 |
  |---|---|---|
  | 1 | 父亲 | 儿子 |
  | 2 | 爷爷（祖父） | 孙子 |
  | 3 | 曾祖父 | 曾孙（重孙） |
  | 4 | 高祖父 ← **爷爷的爷爷** | 玄孙（元孙） |
  | 5 | 天祖父 | 来孙 |
  | 6 | 烈祖父 | 晜孙（昆孙） |
  | 7 | 太祖父 | 仍孙 |
  | 8 | 远祖父 | 云孙 |
  | 9 | 鼻祖 | 耳孙 |

  母系按「外」另立一支（外曾祖父 → 外高祖父 → 外天祖父…），奶奶娘家插「外」（曾外祖父 → 高外祖父 → 天外祖父…），两套不打架
- **俗称 / 别称**：每个正名都带一组民间叫法（`Kinship.TERMS['高祖父'].alias` → 老太爷、祖爷爷、太爷爷；`Kinship.aliasOf('曾孙')` → 重孙、重孙子）。信息卡正名下方显示「又叫 …」，搜索也能按俗称命中原名。各地叫法不同，同一个俗称可能挂在相邻两代上（如「太爷爷」多数地方指曾祖父，也有地方指爷爷的爷爷），词表里两代都收
- **旁系五服**：伯祖/叔祖、姑祖母（姑奶奶）、舅祖父（舅公）、姨祖母（姨婆），外祖一侧对应外伯祖/外叔祖/外姑祖母/外舅祖父/外姨祖母；再下一代接堂叔/堂姑、表叔/表姑、堂舅/表舅，往下接从堂兄弟、表侄/表侄女，再往后一代接侄孙、外甥孙（舅公/姨婆看我）
- **姻亲**：伯母、婶婶、姑父、舅妈、姨父、嫂子、弟媳、姐夫、妹夫、儿媳、女婿、侄媳、孙媳、亲家公/亲家母、岳祖父、祖公公；配偶的兄弟姐妹按「我」的性别区分妻家（内兄/内弟、姨姐/姨妹）与夫家（大伯子/小叔子、大姑子/小姑子）

测试：`node tests/kinship.test.js`（引擎 150 条断言）、`node tests/region.test.js`（区域几何校验 20 条断言）、`node tests/geocode.test.js`（地名搜索合并/纠偏 40 条断言）、`node tests/tile.test.js`（瓦片层选项 17 条断言）、`node tests/secrets.test.js`（防止 key 被提交）、`node tests/actions.test.js`（事件委托一致性：无内联 handler、data-act 全覆盖）

## 隐私

- 数据仅存浏览器 localStorage，不上传任何服务器
- 导出的 JSON 文件请自行保管
- 演示数据使用非私人坐标；真实坐标建议只存在本地与导出文件中
- **API key 不要写进 `config.js`**（它是仓库文件，会随仓库公开）。在应用内点地名搜索框旁的「⚙」填写，只存本浏览器 localStorage；`config.js` 里的 `AMAP_KEY` / `TIANDITU_KEY` 应保持空字符串

## 地名搜索（国内可用性）

默认底图是 Esri 卫星（国内可达），但它只是「兜底搜索源」——Esri 地理编码对国内
村/镇级地名覆盖很差（常返回拼音或不相关结果），OSM 的 Nominatim 在大陆通常不可达。

### 完全不接入 key 的方案

- **Photon 源**（默认已启用）：基于 OSM 数据的免 key 检索，免注册，大陆可达性实测较好，
  直接返回 WGS-84。结果徽章显示「Photon」。局限：OSM 未收录的村名搜不到（覆盖不如高德全）
- **官方坐标拾取器 + 粘贴**：高德坐标拾取器（lbs.amap.com/tools/picker）和百度地图的
  拾取器都是免费网页工具，无需注册。在里面搜地名/点图 → 复制坐标 → 粘贴到本项目搜索框：
  - 直接粘贴（如 `111.2865,30.8345`）→ 自动识别「经度,纬度」顺序与 GCJ-02 基准并纠偏
  - `b:经度,纬度` → 百度拾取器坐标（BD-09）纠偏
  - `w:经度,纬度` → GPS 原始坐标（WGS-84），强制不纠偏
  - `纬度,经度`（境内）→ 与旧版一致，按 WGS-84 原样处理
  境内经纬度范围不重叠（纬 18~54 / 经 73~136），顺序判断不会误判；纠偏说明写在结果的
  地址行里，贴错基准可换前缀重贴
- 原有方式依然可用：地图上直接框选 / 「纬度,经度」直输

### 需要 key 的方案（村镇搜索最准）

国内正规 POI 搜索服务（高德/百度/腾讯/天地图）全部要求 key，没有免 key 的搜索接口。
个人免费注册二选一即可：

- **高德**（推荐，村/镇 POI 覆盖最好）：https://console.amap.com 注册 → 创建应用 →
  添加 Key → 服务平台选「**Web服务**」。key 可以填进 `config.js` 的 `GEOCODE.AMAP_KEY`，
  也可以不改代码——直接点侧栏搜索框旁的「**⚙**」粘贴保存（存本浏览器 localStorage，
  优先于 config.js，并有「保存并测试」验证 key 是否有效）。
  高德返回 GCJ-02 坐标，会自动纠偏成 WGS-84 与底图对齐，无需手动处理。
- **天地图**（国家官方服务）：https://console.tianditu.gov.cn 注册 → 创建应用 →
  类型选「**浏览器端**」→ 把 tk 填到 `config.js` 的 `GEOCODE.TIANDITU_KEY`。
  直接返回 WGS-84，免纠偏。

搜索行为（v2.3 起）：

- 并行请求所有**已配置**的源（没填 key 的源自动跳过），合并去重后按相关度排序展示；
  每条结果带来源徽章。不会再出现「Esri 先返回一个不准的结果就不再尝试其他源」的情况
- 快的源先显示（增量渲染），总耗时约等于最慢的一个源
- 某个源超时/断网后会被记入"暂时连不上"（20 分钟，存 localStorage），期间搜索立即返回、
  不再每次白等 5 秒；点搜索失败卡上的「重试」可清空记忆重新尝试，成功一次也会自动恢复
- 高德 POI 搜不到时自动退回行政区划地理编码（自然村未收录时至少能定位到所属市县镇）
- **搜索只做定位**：点结果只把地图中心移过去——不缩放、不建区域、不改数据；区域请自己用「地图上框选新区域」划定
- 区域边框是红虚线（一直存在，不是搜索画的）
- 全程免网络的选择：搜索框直接输入 `纬度,经度`（如 `31.0,111.0`）

## 瓦片说明

默认卫星底图：Esri World Imagery（免注册免 key）。config.js 可切换本地瓦片目录（`tiles/{z}/{x}/{y}.png`）或配置其他网络源。

v1.8 行为：

- 瓦片加载范围由 `CONFIG.TILE_LIMIT_TO_REGION` 控制：默认 `false`（跟随视口，缩到最小时区域外也有图）；设为 `true` 则只加载当前区域范围（省流量，但区域外留白）
- 平移有**硬边界**：地图拖不出当前区域外扩范围（区域四周各外扩区域尺寸 100%，总显示范围 ≈ 区域×3，`maxBoundsViscosity: 1.0`），像游戏地图"越界移不过去"；超小区域（< 1km）固定外扩 1km，避免边界过小无法拖动。`CONFIG.VIEW.EXPAND_RATIO` 可调，想更紧调小、看更远调大
- 缩放也受限：缩到"区域外扩范围恰好铺满视口"那一级就缩不动了（`syncMapPan` 按视口动态算 `minZoom`，窗口尺寸变化时重算）；绘制新区域 / 放置人物时临时解锁
- 无区域（演示/空档案）时不限制范围
- 建区尺寸校验 `REGION_MAX_SPAN_KM`（默认 20km，超出拦截）/ `REGION_MIN_SPAN_KM`、`REGION_MIN_AREA_KM2`（过小或共线拦截）；手绘闭合即校验，搜索建区超限则弹窗询问
- 打开档案/切换区域时的初始视野：区域按比例外扩后恰好铺满视口（`CONFIG.VIEW.EXPAND_RATIO`，超小区域固定外扩 1km）；无区域时才用 `CONFIG.VIEW.MAX_ZOOM`（15）限制"看全部人物"的视野

## 地图加载优化

底图请求是首屏最慢的一环（Esri 服务器在境外，单片 0.5~2 秒，一屏约 20 片）。现在的优化，都在 `config.js` 的 `TILE` 里可调：

| 优化 | 做法 | 配置项 |
|---|---|---|
| 首屏不浪费 | 视野适配到当前区域**之后**才创建瓦片层，不会先按默认中心下一屏再丢弃 | 自动 |
| **统一 256px 原生瓦片** | 所有缩放级别都用同一套 256px 影像，不会"换级换图"；缩放时 Leaflet 自动按父级瓦片放大/细分过渡 | 固定 |
| **空闲预取** | 停下 0.8 秒后，把"放大一级要用的瓦片"提前下到本地缓存，下次缩放直接出图 | `PREFETCH` |
| 落盘缓存 | 瓦片存 IndexedDB（`kinmap_tiles`）：第二次打开、反复拖动同一片区域 **0 次网络请求**，断网也能看浏览过的范围 | `CACHE`、`CACHE_MAX` |
| 预连接 | `<link rel="preconnect">` 提前完成 DNS + TLS，首屏少等 100~300ms | `index.html` |
| 少发请求 | `updateWhenIdle`：拖动停下才请求；`keepBuffer`：视口外多留几圈，拖动时更少空白 | `UPDATE_WHEN_IDLE`、`KEEP_BUFFER` |
| 原生层级上限 | 超过 `MAX_NATIVE_ZOOM` 只放大低一级的瓦片，不再请求更高层（乡村 z18 常是「Map data not yet available」占位图） | `MAX_NATIVE_ZOOM` |
| 失败占位 | 加载失败显示 1×1 透明图，不出现破图标 | `ERROR_TILE` |

实测（本机，同一视野、清空缓存后进入档案）：

| 场景 | 结果 |
|---|---|
| 首屏铺满（16 级） | 20 片，约 2.9s（视网络） |
| 第二次打开（缓存命中） | **0 次请求 / 381ms** |
| 任意缩放级别 | 同一套 256px 影像，不会出现"这一级清楚、下一级糊" |

## 区域离线包（推荐给网络慢的情况）

侧栏「当前区域」下面有 **⤓ 缓存本区离线图**：把当前区域范围、从当前最小缩放级到 18 级的瓦片**一次性下到本地**（IndexedDB）。

- 会先估算：`16 ~ 18 级，共 106 片，约 1.2 MB`，确认后才开始
- 下载有进度条，可以关掉窗口继续下，也能中途停止（已下的部分保留）
- 下完后再进这个区域：**0 次网络请求**，断网也能看

实测（本机，0.6km 的测试区域）：

| 项目 | 数据 |
|---|---|
| 覆盖层级 | 16 / 17 / 18 级 |
| 瓦片数 | 106 片（约 1.3 MB） |
| 首次下载耗时 | 12.3 秒（4 并发） |
| 再次点击（全部已缓存） | 0.8 秒 |
| **断网后进入该区域** | **9 片（16 级）+ 26 片（17 级）全部从本地加载，网络请求 0，失败 0** |

限制：

- **离线包只缓存地图瓦片**：应用页面本身（HTML/JS/CSS）没有 Service Worker，首次打开仍需联网；
  已打开的页面断网后可正常用已缓存瓦片浏览
- 一次最多下 `TILE.OFFLINE.MAX_TILES`（默认 2500 片 ≈ 30MB），避免 20km 大区域把硬盘塞满；
  超出预算的更高层级仍联网加载
- 只存在**当前浏览器**里（IndexedDB），换设备/换浏览器不会跟随；要带走数据请用「导出数据」（那是人物/区域数据，不含瓦片）
- 缓存会被浏览器在空间不足时清理；「缓存本区离线图」可随时重下补齐

## 地名搜索：搜不到时怎么办

v2.4 起，搜索失败不再把三个「请求超时」甩给用户，而是一张操作卡：

```
联网搜索暂时用不了
几个免 key 的地名服务在你这里都连不上（不影响已有数据）。换一种方式定位：
[在地图上框选区域] [粘贴坐标] [填 key] [重试]
```

- **在地图上框选区域**：进入手绘模式，自己点顶点圈出范围（≥3 点，双击闭合），和平时建区完全一样
- **粘贴坐标**：输入 `112.56,24.99` 即可；高德/腾讯拾取器复制的坐标加 `g:` 前缀会自动纠偏
- 连不上的源记 20 分钟（localStorage），期间搜索**立即返回**而不是再等 5 秒；点「重试」清空记忆重新尝试
